# SenseSheet
SenseSheet  is a full-stack web application developed using the MERN stack (MongoDB, Express.js, React.js, Node.js), enhanced with SQLite, and built with a combination of JavaScript, HTML, CSS, and modern data visualization libraries like Chart.js and Plotly.js. The project provides users with a seamless way to upload Excel files and transform raw data into insightful, interactive visualizations.

🔧 Tech Stack
Frontend: React.js, JavaScript, HTML5, CSS3

Backend: Node.js, Express.js

Database: MongoDB (primary), SQLite (for temporary or lightweight local storage)

Libraries: xlsx (for parsing Excel files), Chart.js, Plotly.js (for rendering dynamic charts)

✨ Key Functionalities
Excel Upload Support: Users can upload .xls or .xlsx files directly from their device.

Data Parsing: The system uses xlsx to read Excel sheets and convert them into JSON format for processing.

Graph Generation: Users can choose the type of chart and customize inputs for a clean and visual representation.

Multiple Chart Types Supported:

Line Charts

Bar Graphs (Vertical & Horizontal)

Pie Charts

Box Plots

Area Charts

Scatter Plots

Doughnut Charts

Real-time Data Preview: Users can preview and filter the data before generating visualizations.

Custom Configuration: Modify axis labels, colors, chart titles, and more for a personalized experience.

Responsive UI: Fully responsive and user-friendly design for desktops and mobile devices.

👥 Use Case & Target Audience
Students & Educators: To convert tabular data into visual learning aids or presentations.

Business Analysts & Data Professionals: Quickly analyze and visualize datasets for reporting.

Developers: As a base for data dashboard or reporting tools.

Goal-
The goal is to offer a no-code, visual analytics platform where users can interactively analyze Excel data without needing to open Excel or use manual charting. By combining modern web technologies with robust chart libraries, this project delivers a smooth, efficient, and visually rich data analysis experience.
